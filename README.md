# Connect Four Two-Player In-Browser Game
Two-player Connect Four with animated disc drops, win detection, and persistent scoreboard.
## Features
- 7×6 grid with click-to-drop disc mechanics
- Detects wins in all 4 directions and highlights the winning four discs
- Undo last move button
- Scoreboard persisted in localStorage
- Animated CSS disc drop transition
- New game and reset score buttons
## Tech
Static SPA · Tailwind CDN · localStorage
